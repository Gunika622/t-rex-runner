# 🦖 T-Rex Runner

An AI-assisted T-Rex Runner game built with HTML, CSS, and JavaScript.

## 🎮 Features

- 🦖 T-Rex character
- 🌵 Obstacles
- ⬆️ Jump mechanic
- 🏆 Score system
- 💥 Collision detection
- 🔄 Restart option
- ⚡ Increasing difficulty

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- GitHub
- AI-assisted development

## 🚀 About the Project

This project is being developed as a fun learning project to understand
game development, JavaScript, animations, collision detection, and
AI-assisted programming.

## 📌 Status

🚧 Currently under development.
